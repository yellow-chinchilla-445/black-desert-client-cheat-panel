# Black Desert Client Settings Panel — feature reference

Start with display groups, organize research notes, and keep configuration records close at hand. These are the main areas covered by Black Desert Client Settings Panel.

| Section | Description |
|---|---|
| Display groups | Display or performance-related options, with space for configuration and comparison information. |
| Research notes | A dedicated section for research notes and the configuration details associated with that area. |
| Configuration records | A dedicated section for configuration records and the configuration details associated with that area. |

The project page follows the same section structure.
